# Verificar APIs externas

**No escribas código ni modifiques nada fuera de `docs/05-fuentes-externas.md`.**

Para cada fuente de `docs/05` (open.er-api.com, BCRP/SUNAT para tipo de cambio, USGS, Nager.Date, Open-Meteo, IGP para sismos, peru-consult-api, apiconsulta.dev y el padrón reducido de SUNAT):

1. Abre su documentación oficial vigente.
2. Confirma: URL base, parámetros, formato real de respuesta (con un ejemplo), límites de uso, autenticación, atribución obligatoria y si permite uso en un sitio con publicidad.
3. Marca cada dato como **confirmado** (con el enlace de donde lo viste) o **no confirmado**. No supongas.

Al final entrégame una tabla resumen por fuente y una lista de decisiones que debo tomar yo (por ejemplo, si algún término de uso exige plan de pago). Actualiza `docs/05-fuentes-externas.md` quitando la marca VERIFICAR solo de lo confirmado.
